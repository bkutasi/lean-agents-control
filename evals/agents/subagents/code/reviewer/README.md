# Reviewer - Evaluation Tests

## Overview

**Agent:** `CodeReviewer`  
**Parent Agent:** `openagent`  
**Description:** Code review, security, and quality assurance

## Test Structure

```
code/reviewer/
├── config/
│   └── config.yaml          # Test configuration
├── tests/
│   └── smoke-test.yaml      # Basic sanity check
├── prompts/                 # Prompt variants (future)
└── README.md                # This file
```

## Running Tests

### Standalone Mode
Tests the subagent directly (forces `mode: primary`):

```bash
# Using npm
npm run eval:sdk -- --subagent=code-reviewer

# Using Makefile
make test-subagent SUBAGENT=code-reviewer

# Verbose output
npm run eval:sdk -- --subagent=code-reviewer --verbose
```

### Delegation Mode
Tests via parent agent (real-world usage):

```bash
# Using npm
npm run eval:sdk -- --subagent=code-reviewer --delegate

# Using Makefile
make test-subagent-delegate SUBAGENT=code-reviewer
```

2. Follow the YAML schema from `evals/agents/shared/tests/golden/`
3. Add appropriate tags: `subagent`, `code-reviewer`, suite name
4. Update this README with test description
